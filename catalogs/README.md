# Image catalogs

Generated by `images/catalog.sh` after every publish from `main`; do not edit.

`catalog-<flavor>-<distro>.yaml` is a `ClusterImageCatalog` named
`cnmsql-<flavor>-<distro>` mapping each series to its newest published image by
immutable tag and digest. See
[the design](../design/001-image-supply-chain.md#catalogs-s8).
